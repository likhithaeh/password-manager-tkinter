Password Manager

A desktop password manager built with Python and Tkinter.

<img width="524" height="400" alt="image" src="https://github.com/user-attachments/assets/232d3ff3-b746-4eb2-910d-8b7708661696" />

Features
- Graphical interface built with Tkinter
- Random strong password generator
- Saves website, email and password entries
- Copies the generated password to the clipboard
 
Usage
1. Enter the website, email
2. Click Generate Password (or type your own)
3. Click Add to save the entry

Project structure

├── main.py     # GUI and logic
└── README.md

What I learned
- Building GUIs with Tkinter (layout, widgets, events)
- File handling and data persistence in Python
- Input validation and user feedback with message boxes
